# Accessibility Audit Report

Website audited: https://www.india.gov.in

Issue 1: Missing focus outlines on buttons when using the Tab key (Priority: High)
Issue 2: Text contrast is too light on white backgrounds (Priority: High)
Issue 3: Images in the header lack alternative (alt) text for screen readers (Priority: Medium)
Issue 4: Search input box is missing an explicit HTML <label> tag (Priority: High)
Issue 5: No "Skip to main content" link for keyboard users (Priority: Medium)
